# GMP 知识库语义检索（RAG 项目一）

基于 OCR + 向量检索的医疗器械法规文档检索系统。上传扫描版标准 PDF，
自动识别文字、切块、向量化，支持按语义查找相关条款。

## 业务背景
医疗器械质量体系文档（GB/T 42061）多为扫描件，且条款
分散在几十页中，工程师人工翻阅效率低。本项目用 RAG 思路实现
"输入问题 → 返回相关条款原文+页码"，作为文档查阅辅助工具。

## 技术栈
- OCR：RapidOCR（扫描件文字识别）
- 向量模型：BAAI/bge-small-zh-v1.5（中文语义向量）
- 向量库：ChromaDB（本地持久化）
- 相似度：余弦相似度，阈值过滤（0.55）

## 核心流程
扫描PDF → OCR逐页识别 → 按页切块(过滤附录) → Embedding向量化 → Chroma入库 → 语义检索
