# GMP 知识库 RAG 问答系统（gmp-rag）

基于 OCR + 向量检索 + 大模型的医疗器械法规文档问答系统。
输入自然语言问题，自动检索 GB/T 42061 / ISO 13485 相关条款，
由大模型生成带来源页码的回答；资料外不答，控制幻觉。

## 业务背景
医疗器械质量体系文档多为扫描件、条款分散在几十页，工程师人工翻阅效率低。
本项目实现"问题 → 检索相关条款 → 大模型基于条款作答（标页码）"，
作为文档查阅辅助工具。

## 技术栈
- OCR：RapidOCR + PyMuPDF（DPI 300，扫描件逐页识别）
- 向量模型：BAAI/bge-small-zh-v1.5（512维）
- 向量库：ChromaDB（本地持久化，余弦相似度）
- 生成模型：DeepSeek（deepseek-chat，OpenAI 兼容接口）
- 防幻觉：检索阈值过滤 + Prompt 限定只用资料 + 无资料直接拒答

## 核心流程
扫描PDF → OCR识别 → 按页切块(过滤附录) → 向量化 → Chroma入库
→ 语义检索(阈值0.50) → 拼Prompt(系统提示+参考块+问题) → DeepSeek生成 → 答案+来源页码

## 目录
- week3/：OCR 入库 + 语义检索（Release v0.1.0）
- week4/：接入 DeepSeek 文档问答、多轮、来源标注、拒答（Release v0.2.0）

## 使用
```bash
cd week4
python chat.py        # 连续问答；/clear 清空历史，/exit 退出
python eval.py        # 跑测试集评估
```

## 数据与合规
标准原文（GB/T 42061-2022 / ISO 13485:2016）受版权保护，不纳入仓库，
已通过 .gitignore 排除。本系统输出仅供文档查阅辅助，不替代正式体系文件，
相关结论须经质量/法规人员复核。
